Entrar

A chave fica só neste aparelho. Ela é usada para gravar os artigos direto no repositório do coletivo.
Como conseguir a chave de acesso
  1. Peça ao administrador para te adicionar como colaborador do repositório no GitHub.
  2. Entre no GitHub e abra Configurações → Tokens de acesso → Novo token.
  3. Em Repository access, escolha Only select repositories e marque o repositório do coletivo.
  4. Em Permissions → Repository permissions → Contents, escolha Read and write.
  5. Gere o token, copie e cole aqui.
